# cisco-dual-stack-lab

**Tools:** Cisco Packet Tracer | **Completed:** December 2026 | **Type:** Individual

[![Project Preview](./preview1.png)](https://drive.google.com/file/d/16kFywXLkdmvKwmww7Wvb8M3_8N-SykFo/view?usp=sharing)

A multi-subnet network infrastructure design featuring IPv4/IPv6 dual-stack routing, device hardening, and custom VLSM addressing across 3 local area networks.

## Full Documentation
- [Presentation (PDF)](https://drive.google.com/file/d/16kFywXLkdmvKwmww7Wvb8M3_8N-SykFo/view?usp=sharing)

## Key Features
- **IP Subnetting (VLSM):** Calculated and assigned IP addresses for the `192.168.10.0/24` network to divide it into multiple subnets.
- **Dual-Stack & Routing:** Configured simultaneous IPv4 and IPv6 addressing and static routing across all subnets.
- **Device Hardening:** Enabled SSH with RSA keys, encrypted passwords, MOTD banners, `login block-for` brute-force protection, and shut down unused switch ports.
- **Verification:** Validated network reachability using `ping`, `tracert`, `arp`, and routing/MAC address tables.
